# Citation

If you use CSI/CVI from this pipeline, cite the original paper:

Candia-Rivera, D., de Vico Fallani, F., & Chavez, M. (2025).
Robust and time-resolved estimation of cardiac sympathetic and parasympathetic indices.
*Royal Society Open Science*, 12(1), 240750.
https://doi.org/10.1098/rsos.240750

Authors’ MATLAB code:
https://github.com/diegocandiar/robust_hrv

In the paper the parasympathetic index is often named **CPI**. In the MATLAB/Python code it is named **CVI**. Same quantity.
